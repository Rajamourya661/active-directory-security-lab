## Presentation Tips

1. Lead with **outcomes** (detected Kerberoast in &lt;15 min, reduced BloodHound paths by X%).
2. Show **one** BloodHound graph and **one** detection screenshot (redacted).
3. Emphasize **authorization** and isolated lab ethics.
4. Link to public repo; keep hashes and domain exports private.
